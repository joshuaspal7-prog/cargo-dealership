First-time setup (about 3 minutes)

This page saves your cars straight to your website. To do that, it needs a GitHub access key. You create it once, and it stays only on this phone or computer. Never send the key to anyone.

  1. On this device, open github.com/settings/personal-access-tokens/new and sign in.
  2. Token name: Car-Go admin. Expiration: pick the longest option offered.
  3. Repository access: choose Only select repositories, then pick cargo-dealership.
  4. Under Permissions, click Repository permissions, find Contents and set it to Read and write.
  5. Click Generate token, copy the key (it starts with github_pat_) and paste it below.
